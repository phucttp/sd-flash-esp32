Tại sao cần FlashPod?

Nạp firmware ESP32 truyền thống có nhiều bất tiện

💻

Phụ thuộc laptop

Mỗi lần flash cần mang theo PC, cài driver, mở IDE. Bất tiện khi làm việc ngoài hiện trường.

⏱️

Tốn thời gian setup

Cài ESP-IDF, Arduino IDE, cấu hình COM port... Mất hàng chục phút chỉ để flash 1 board.

🏭

Khó scale production

Sản xuất hàng loạt cần nhiều PC hoặc đắt tiền mua programmer chuyên dụng.

GIẢI PHÁP

FlashPod - Flash Anywhere

Thiết bị flash di động với đầy đủ tính năng chuyên nghiệp

📱

Menu OLED trực quan

Giao diện 128x32 pixels, cuộn danh sách firmware, hiển thị tiến độ flash real-time

💾

Thư viện trên SD Card

Lưu trữ không giới hạn firmware. Quản lý bằng file JSON đơn giản

🌐

WiFi Sync

Tải firmware từ server/GitHub qua WiFi. Mã hóa AES-128-CBC bảo mật

✅

MD5 Verification

Kiểm tra tính toàn vẹn firmware sau khi flash. Đảm bảo 100% chính xác

🔧

Tool PC đi kèm

FlashPorter - GUI để chuẩn bị thẻ SD, mã hóa firmware, push lên cloud

QUY TRÌNH

Cách sử dụng

Chỉ 4 bước đơn giản để flash firmware

1

Chuẩn bị SD

Dùng FlashPorter để copy firmware vào thẻ SD

2

Kết nối Target

Nối 4 dây UART giữa FlashPod và ESP32 cần flash

3

Chọn firmware

Cuộn menu bằng UP/DOWN, nhấn OK để chọn

4

Done!

Đợi progress bar chạy xong, target tự khởi động

THÔNG SỐ

Thông số kỹ thuật

🎛️ Hardware

  • MCU ESP32-C3
  • Display SSD1306 OLED
  • Resolution 128x32 px
  • Storage MicroSD (FAT32)
  • Buttons 3 (UP/DOWN/OK)
  • Interface I2C + SPI + UART

⚡ Flash Protocol

  • Library esp-serial-flasher
  • Baudrate High-speed
  • Bootloader @ 0x1000
  • Partition @ 0x8000
  • Application @ 0x10000
  • Verification MD5 checksum

🌐 Connectivity

  • WiFi 2.4GHz
  • Config Captive Portal
  • Download HTTPS
  • Encryption AES-128-CBC
  • Server GitHub / Custom
  • Sync Smart Delta
